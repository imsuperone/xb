# 小白 · AstrBot 插件 `astrbot_plugin_xbbot` v0.68.36

> 🎮 1:1 深度复刻经典群互动玩法，包含 奴隶 / 签到 / 银行 / 娱乐 / 精灵 / 坐骑 / 帮派 / 冒险 / 超管 全套 28 大系统与 WebUI 现代化管理控制台。

### ✨ v0.68.36 核心特性与更新：
- ☁️ **WebDAV 频控与 HTTP 429 根治**：弃用深层遍历，改用 WebDAV 标准 RFC 4918 OPTIONS 轻量嗅探，增加远端目录验证缓存，彻底规避服务商 QPS 频控限制与 Too Many Requests；
- 📦 **SQLite 数据库自包含 100% 完整配置与用户资产**：全量系统配置在保存时同步持久化至 SQLite `kv` 表，冷备前确保落盘，单一 `.db` 自包含所有配置与用户数据并支持免 JSON 自愈；
- 🎨 **WebUI 现代化体验深度重构**：移除冗余快照面板；测试 WebDAV 与立即上传云端规范移入配置卡片并支持点击列表选择数据库上传；重构 WebDAV 开关为统一的 iOS 卡片滑块；
- 🪟 **弹窗体验与版本检测优化**：全局模态弹窗新增右上角 `✕` 与「确定」关闭按钮；修复页面打开时重复检测两次版本的缺陷，消除常驻占位横幅，按需弹窗展示；
- ⚡ **毫秒级极速响应与零阻塞保障**：主事件循环绝对零阻塞，全异步后台守护备份，全 SQLite WAL 模式与内存高速缓存保障。

### 📦 安装与使用：
1. **AstrBot 插件管理器**：在 AstrBot 插件市场或「安装插件」处填入仓库地址 `https://github.com/imsuperone/xb` 即可一键安装；
2. **Web 管理后台**：在 AstrBot 后台进入「小白」页面，即可使用全功能管理大屏与玩法配置。
