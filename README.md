# 小白 · AstrBot 插件 `astrbot_plugin_xbbot` v0.7.1

> 🎮 1:1 深度复刻经典群互动玩法，包含 奴隶 / 签到 / 银行 / 娱乐 / 精灵 / 坐骑 / 帮派 / 冒险 / 超管 全套 28 大系统与 WebUI 现代化管理控制台。

### ✨ v0.7.1 核心特性与更新：
- 🕒 **WebDAV 远端归档中文日期与上海时区 (UTC+8)**：时间格式化为标准中文日期时间，彻底告别英文 GMT 串；
- 🗑️ **WebDAV 远端备份支持在线直接删除**：集成二次危险确认与 HTTP DELETE 远端删除，实时无感刷新列表；
- 🚀 **版本检测纪元比对与 CDN 防缓存强化**：彻底杜绝旧版本倒流误报，版本号严格按 `0.7.xx` 规则演进；
- 🎯 **模态弹窗 Emoji 全局智能去重**：根治所有双重 Emoji 图标堆叠问题，界面清爽统一；
- ☁️ **WebDAV 远端备份归档与一键快捷热恢复**：支持实时浏览 WebDAV 远端备份归档，提供一键热恢复与本地下载；
- 🛡️ **彻底根除双份备份与重复上传**：增加 5 秒全局时间窗口防抖，复用最新备份路径，切断自动与手动上传的重叠并发；
- 🎨 **WebUI 按钮视觉反馈与全局 Toast 修复**：补齐 `#toast` DOM 浮层与样式，测试与上传按钮增加忙态与禁用保护，操作结果直观弹窗回显；
- 📦 **SQLite 数据库自包含 100% 完整配置与用户资产**：全量系统配置在保存时同步持久化至 SQLite `kv` 表，冷备前确保落盘，单一 `.db` 自包含所有配置与用户数据；
- ⚡ **毫秒级极速响应与零阻塞保障**：主事件循环绝对零阻塞，全异步后台守护备份，全 SQLite WAL 模式与内存高速缓存保障。

### 📦 安装与使用：
1. **AstrBot 插件管理器**：在 AstrBot 插件市场或「安装插件」处填入仓库地址 `https://github.com/imsuperone/xb` 即可一键安装；
2. **Web 管理后台**：在 AstrBot 后台进入「小白」页面，即可使用全功能管理大屏与玩法配置。
